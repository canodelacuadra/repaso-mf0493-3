16 preguntas · 2 por apartado · corrección al final

1

¿Qué diferencia principal hay entre una web estática y una dinámica?

Respuesta correcta: B. En la web estática el HTML se sirve tal cual; en la dinámica se genera con datos (por ejemplo, desde una base de datos) en cada petición.
2

¿Para qué se utiliza React?

Respuesta correcta: C. React es una biblioteca de JavaScript para construir interfaces de usuario, especialmente aplicaciones de una sola página (SPA).
3

En WordPress, ¿qué se usa para publicar contenidos periódicos como noticias o artículos de blog?

Respuesta correcta: B. Las entradas están pensadas para contenido cronológico y se agrupan por categorías y etiquetas; las páginas son para contenido estático como «Sobre nosotros».
4

En WordPress, ¿qué permiten los roles y capacidades (permisos)?

Respuesta correcta: C. Administrador, editor, autor, colaborador y suscriptor tienen permisos distintos: publicar, editar, moderar comentarios, etc.
5

¿Qué elemento de WordPress controla principalmente la apariencia y el diseño del sitio?

Respuesta correcta: B. El tema define la estructura visual, los colores, la tipografía y las plantillas; los plugins añaden funcionalidades.
6

¿Para qué sirve el plugin Smush?

Respuesta correcta: C. Smush comprime las imágenes sin perder apenas calidad, lo que reduce el peso de la web y mejora su velocidad de carga.
7

En WooCommerce, ¿qué es un producto variable?

Respuesta correcta: C. Las variaciones permiten vender tallas, colores o tamaños con SKU, precio y stock independientes dentro de un mismo producto.
8

¿Qué significa que un pedido de WooCommerce está «Procesando»?

Respuesta correcta: B. El flujo habitual es Pendiente → Procesando → Completado: en «Procesando» el pago está recibido y queda preparar y enviar.
9

¿Cuál es la función principal de un sitemap (mapa del sitio)?

Respuesta correcta: B. El sitemap.xml lista las URLs importantes para que Google y otros buscadores rastreen el sitio de forma más completa.
10

¿Cuál de estas acciones pertenece al SEO On Page y no al SEO técnico?

Respuesta correcta: B. El SEO On Page trabaja el contenido y sus etiquetas; el SEO técnico se ocupa de rastreo, velocidad, HTTPS, redirecciones, etc.
11

¿Qué garantiza el HTTPS?

Respuesta correcta: B. El certificado SSL/TLS cifra el canal de comunicación y además verifica la identidad del sitio; no sustituye a las actualizaciones ni garantiza el primer puesto en Google.
12

Respecto al RGPD, ¿qué debemos hacer al recoger datos personales en un formulario?

Respuesta correcta: B. Hay que informar de quién trata los datos, para qué y durante cuánto tiempo, y recabar una aceptación libre y explícita antes de enviarlos.
13

¿Cuál es la diferencia entre Git y GitHub?

Respuesta correcta: B. Git funciona en tu ordenador sin conexión; GitHub (o GitLab, Bitbucket…) añade un repositorio remoto y herramientas de colaboración.
14

¿Para qué se utiliza FileZilla?

Respuesta correcta: A. FileZilla es un cliente FTP/SFTP: conecta con el hosting y permite transferir archivos entre el ordenador local y el servidor.
15

¿Qué comando de Git crea un repositorio nuevo en la carpeta actual?

Respuesta correcta: C. git init crea la carpeta oculta .git y empieza a registrar versiones en ese directorio; git clone, en cambio, copia un repositorio ya existente.
16

¿Qué hace exactamente git add .?

Respuesta correcta: B. git add prepara los cambios para el siguiente commit; después git commit los guarda en el historial y git push los envía al remoto.
